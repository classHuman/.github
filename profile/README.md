# classHuman AI

**Generative AI software engineering and research. Humans keep final authority.**

classHuman AI LLC (Washington, USA, est. 2026) is a generative AI software engineering and research firm. We build and audit AI systems for small businesses and government, and research how AI agents are governed. ## The problem we work on

An agent acts. It calls tools, changes state and spends money. Every safeguard a team claims (step limits, permissions, approvals, logs) is either built into the harness or it's a line in a policy document. The failures we see sit in the harness: a loop with no stop condition, a tool that does more than its name says, a gate that warns and continues, a sign-off no one reads, a log that misses the reason.

**Inherited estates.** Between 2021 and 2026 companies assembled AI systems as they went: prompt chains, RAG v1, a fine-tune or two, a vector store, orchestration glue, a vendor lock-in no one chose on purpose. It works, mostly. And now no one inside can explain what it does, audit it, or sign off on replacing it. That is a legacy system that happens to be two years old. Someone has to establish what it does, sort the data underneath it, and put a human-controlled boundary between the old estate and the new one so the replacement can be signed. That is both our research track and our audit service.

## How we research

**Questions first.** Each research page states its question, method and measure up front.

**Measures before results.** We define how we'll measure before we run anything, and no page states a result we haven't produced. Right now every open question reads "Open. No results yet."

**Sources cited.** Every external claim links to its primary source. Frameworks are "mapped to", and a run result is evidence for a reviewer.

**Agents propose, humans sign.** Proposals pass gates. A named person signs. A failed gate denies the action, records why, and escalates. There is no "warn and continue."

Research prose and checklists are CC BY 4.0. Code is Apache-2.0.
