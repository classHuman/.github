## The Control Layer — Five Gates

An agent that can only read is a demo. The moment it can write, spend, or send, it needs five answers:

| Gate | The question it answers |
|---|---|
| **Registration** | Is this agent known? |
| **Validation** | Is this action legitimate, checked before it happens? |
| **Revocation** | Can authority be withdrawn, right now? |
| **Escalation** | What happens when confidence is low? |
| **Human-in-the-loop** | Is final authority actually held by a person? |

Fail-closed throughout: a failed gate denies the action, records the refusal, and escalates to a named human.

## Research & Products

The discipline underneath the client work — R&D, not the invoice line.

### TACO Loop
A decision-control architecture for unknown-data environments: **Take In Unknowns → Assess and Align → Choose Correctly → Operate and Observe Outcome.**

Core product law: *unknown data must increase decision discipline, not model confidence.*

White Paper v1.0 published July 2026; Mathematical Model v0.1 (guardrail function, QRF escalation, drift model, audit hash-chain). [Read more →](https://classhuman.org/product)

### Ag3nt24
The proof layer: gated agent actions that produce signed, append-only receipts — so what an agent did is provable, not just logged. A failed gate denies, records the refusal, and escalates to a named human. [Read more →](https://classhuman.org/ag3nt24)

### Asymptote
A static time and space complexity (Big-O) estimator for Python, built for agents: per-function complexity, confidence, evidence, and the unknowns it can't decide. CLI, agent tool, or MCP server. [Read more →](https://classhuman.org/asymptote)
